# Fotografías del alojamiento

Añade aquí únicamente fotografías originales de Homun cuyo uso para este sitio esté autorizado. No se descargaron imágenes del anuncio ni se incluyeron fotos de stock o generadas.

La galería espera estos archivos WebP:

- `sala.webp`
- `cocina.webp`
- `recamara-principal.webp`
- `recamara-secundaria-1.webp`
- `recamara-secundaria-2.webp`
- `bano.webp`
- `balcon.webp`
- `alberca.webp`
- `areas-comunes.webp`

En `src/config/property.ts`, `galleryItems` determina cuáles aparecen en la galería y sus textos alternativos. Confirma que cada foto corresponda al texto antes de activarla. La foto principal del hero se puede configurar como un archivo local adicional y sustituir el marcador de `src/app/page.tsx`.
