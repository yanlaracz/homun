# Fotografías del alojamiento

Las fotos terminadas en `-retocada.png` se mejoraron digitalmente a partir de imágenes proporcionadas por el propietario. La luz, los colores y algunos detalles pueden diferir de la escena original. La imagen de acceso residencial se excluyó de la publicación.

La galería usa: `sala-retocada.png`, `recamara-retocada.png`, `jardin-retocado.png`, `alberca-retocada.png` y `camastros-retocados.png`.
