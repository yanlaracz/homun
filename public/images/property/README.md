# Fotografías del alojamiento

Fotografías originales proporcionadas por el propietario. Se conservan sin alteraciones y se muestran con sus espacios correctamente identificados. La imagen de acceso residencial se excluyó de la publicación.

La galería usa: `sala.jpeg`, `comedor.jpeg`, `recamara-principal.jpeg`, `recamara-dos.jpeg`, `recamara-tres.jpeg`, `bano.jpeg`, `alberca-dia.jpeg`, `alberca-atardecer.jpeg`, `camastros.jpeg`, `areas-verdes.jpeg` y `juegos.jpeg`.
